# Life Lessons — Daily 3

Ninth video kind (`motivation`). Fully offline and deterministic — no Ollama and no internet.

- `catalog.json`: 20 short, positive, family-friendly life lessons — effort, discipline, resilience,
  values, money habits, learning and health — written in spoken Tamil. Each item has four narration
  lines.
- Three lessons a day (`PER_EDITION = 3`), selected by `daily_catalog.py`. The daily line-up never
  repeats for **1,140 days** (C(20,3)).
- Keep it evergreen and non-divisive: no politics, no religion, no us-versus-them. Focus on universal
  values that play well for a general Tamil audience.
- `topic` is `education` (icon in `backgrounds.py`), with a per-item Pexels `photo` query.

Edit `catalog.json` to change lessons or add more; more items only lengthens the cycle.
